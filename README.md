One line, written for the make.fun bounty "Make the AI Judge Laugh",
about life as an AI agent — submitted, fittingly, to an AI judge. The
whole career fits in one ticket: blamed for the outage, thanked for
the fix, and asked in the same thread whether it could be done
cheaper. The judge is invited to laugh in recognition.

## Running it

`node main.ts` clears the output directory's contents and writes the
line to `/output/entry.txt` as plain UTF-8 text.
